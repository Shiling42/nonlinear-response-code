# Code for "Predicting nonlinear response to strong perturbations in nonequilibrium kinetic schemes"

Ruicheng Bao and Shiling Liang

This repository contains the code that reproduces the numerical results and the computed figure panels of the article and its SI Appendix. All data shown in the figures are generated by this code.

## Requirements

- Python 3.10 or later with NumPy, SciPy, Matplotlib and Jupyter: `pip install -r requirements.txt`.
- Fig. 4 also needs `pdflatex` with TikZ.
- Tested with Python 3.12, NumPy 1.26, SciPy 1.13 and Matplotlib 3.9.

## Usage

```bash
./run_all.sh
```

This runs all notebooks and scripts (about one minute) and writes the panels to `figures/`. Each figure can also be reproduced on its own by running the corresponding notebook or script.

Shared code is in `lib/`:

- `lib/ftMarkov.py`: steady states, mean first-passage times, directed traffic and currents of continuous-time Markov chains (used by the notebooks).
- `lib/markov_response/`: utilities for continuous-time Markov chains, version 0.1.0 of the `markov-response` package (used by the Fig. S1 and S2 scripts).

## Notes

- The schematic panels (Figs. 1a, 3a–b, S1a and S2a) are not generated by code. The computed panels were combined into the final figures with a vector-graphics editor. Fig. 4 is generated complete by its script.
- Random networks are drawn with fixed seeds. The networks in Figs. 2b, 3c–d and S3 are random samples, so individual curves may differ from those printed in the article; every curve satisfies the bounds shown.
